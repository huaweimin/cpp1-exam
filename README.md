# C++ 一级在线考试系统

电子学会青少年软件编程等级考试（C/C++）一级在线模拟考试系统。

## 功能

- 真题在线答题（单选/判断/编程）
- 客观题自动批改，即时出分
- 逐题答案解析 + 参考代码对照
- 教师成绩面板 + CSV 导出
- 数据存 localStorage，零后端零数据库

## 本地开发

```bash
npm install
npm run dev
```

## 部署

推送到 GitHub 后，在 Vercel 导入仓库即可一键部署。

## 技术栈

React 18 + TypeScript + Vite + Ant Design + Tailwind CSS
