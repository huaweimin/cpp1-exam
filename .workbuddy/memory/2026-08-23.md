## 深夜：修复交卷重复提交/重复记录 bug ✅

**现象**：本地 dev (`npm run dev`) 每次交卷后「我的练习记录」出现 2 条重复记录，Network 面板看到 `examsync` 被请求 2 次。

**根因**：React 18 `<StrictMode>` 在开发环境会双重挂载组件，导致 `ResultPage` 的 `useEffect` 执行两次：`saveResult()` 无脑 push 产生 2 条本地记录，`pushResult()` 跟着把 2 条都推上去。

**修复**
1. `src/utils/storage.ts`：`saveResult()` 改为按 `(studentName, examId, submittedAt)` 幂等保存，重复调用不会追加
2. `src/utils/storage.ts`：`getAllResults()` 读取时按同样主键去重，自动屏蔽历史脏数据
3. `src/pages/ResultPage.tsx`：增加 `useRef` 推送锁，确保同一 result 只 `pushResult()` 一次

**验证**：`npm run build` 通过。开发环境 StrictMode 下刷新 ResultPage 也不再重复 push。
