## Monaco 按需加载优化（11:20）

- 用户确认做 Monaco 按需加载以加快国内首屏访问。
- **根因**：`main.tsx` 入口 `import './utils/monacoSetup'`，而 monacoSetup 同步 `import * as monaco from 'monaco-editor'`（~4MB），Monaco 引擎全部打进首屏 bundle。
- 改造：
  - `monacoSetup.ts` 改为导出 `initMonaco(): Promise<void>`，内部 `import('@monaco-editor/react')` + `import('monaco-editor')` + worker 动态加载，配置 `window.MonacoEnvironment` + `loader.config({ monaco })` + `loader.init()`，promise 缓存幂等。
  - `main.tsx` 删除 `import './utils/monacoSetup'`。
  - `CppSandbox.tsx`：Editor 改 `React.lazy(() => initMonaco().then(() => import('@monaco-editor/react').then(m => ({ default: m.Editor }))))`，Suspense fallback 显示 Spin「编辑器加载中…」（340px 占位防跳动）。`OnMount`/`EditorProps` 保留 type-only import（编译期擦除）。
- 构建结果：首屏入口 `index-BoczyKsj.js` 1,072KB（gzip 342KB），Monaco 引擎拆为异步 chunk `index-BmpPRkSi.js` 4,001KB（gzip 1,034KB）+ worker + cpp tokenizer 小 chunk。
- agent-browser 验证（本地 preview + 线上 cppexam.top 双确认）：首屏 resource entries 无 `BmpPRkSi`/worker ✅；进入编程题才请求引擎/worker/cpp chunk ✅；`.monaco-editor` 正常渲染、setValue 可注入、Wandbox 编译运行返回输出 ✅。
- 部署：Vercel `cd dist && vercel deploy --prod --yes` → 线上 index.html 引用与本地 dist 一致（index-BoczyKsj.js）。commit `b5c4f47` 已推送。
- 备注：主包仍 1MB（react+antd 全量），后续可考虑 antd 按需 / manualChunks 进一步优化，非本次范围。

## antd 按需 + manualChunks 分包优化（11:38）

- 用户确认继续做 antd 按需 + manualChunks。
- **antd 按需结论**：全项目 antd/icons 均为具名导入（`import { X } from 'antd'`），antd v5 + CSS-in-JS 天然按需，未引全量 CSS，无需改代码。tree-shaking 实测生效（未用组件不进包）。
- **manualChunks**（`vite.config.ts`）：函数形式按模块路径分包：
  - `react-vendor`：`/react/`、`/react-dom/`、`/scheduler/` → 157.66KB（gzip 50.7KB）
  - `antd-vendor`：`/antd/`、`@ant-design`、`/rc-`、`@rc-component`、`/dayjs/` → 865KB（gzip 272.5KB）
  - `cloudbase-vendor` 分支保留但不命中——**关键发现**：前端 `cloudSync.ts` 用 fetch 直连公开路由，未引入 `@cloudbase/js-sdk`（那是云函数侧依赖），SDK 被 tree-shaking 完全摇掉。
  - 坑：@ant-design/icons 单独拆包会与 antd-vendor 形成 **Circular chunk**（antd 组件内部引用 icons），已合并回 antd-vendor；`chunkSizeWarningLimit: 900` 消除误报（Monaco 4MB 异步 chunk 告警保留，不碍事）。
- 最终首屏：应用 65KB（gzip 24.7KB）+ react-vendor 158KB（gzip 50.7KB）+ antd-vendor 865KB（gzip 272.5KB）= gzip ~348KB。总量与单包持平，但 vendor 长缓存生效（业务更新只重下 25KB），且消除循环/超大 chunk 告警。
- 验证：本地 preview + 线上 cppexam.top——首屏仅加载 3 个 chunk 且无 Monaco；进入考试后 Monaco 引擎仍按需加载、编辑器渲染正常。
- 部署：Vercel，线上 index.html 与本地 dist 引用一致。commit `ce35baf` 已推送。
- 可选后续：页面级 React.lazy（Exam/Result/Teacher/Records 页）可进一步把 antd 组件按页面切分，首屏可降到 ~250KB gzip，需改 App.tsx 路由结构。**用户已明确暂不做。**
