## 新增 C/C++ 一级「编程专项模拟卷」两套（每卷 5 道编程题）

背景：学生编程题练习量不足，基于 Liuser's OJ 题单 https://tctm.cpolar.cn/training/18
（青少年软件编程 C 语言等级一级考试试题，118 道编程题）组卷，按难度从易到难排列。

### 交付物
- `src/data/progMockExams.ts`（新建）：`progMock1` / `progMock2`，每题 20 分共 100 分、及格 60、限时 90 分钟。
  - 卷一 基础过关（★→★★★）：4427 我是小小程序员 / 4236 加一 / 4280 长方形面积 / 4571 温度转换 / 4209 成绩判定
  - 卷二 能力提升（★★★→★★★★★）：4281 成绩等级转换 / 4238 整数的立方和 / 4394 奇偶分家 / 4239 自整除数 / 1217 金币
- `output/编程专项模拟卷-学生版.html`、`output/编程专项模拟卷-教师版(含答案).html`：A4 可打印卷面。
- `src/data/exams.ts`：allExams 追加 `...progMockExams`。

### 代码改动
- `ExamPage.tsx` / `ResultPage.tsx`：分区标题改为条件渲染 + 动态中文序号（原先纯编程卷会渲染出空的「一、单选题（共 0 分）」区块）。

### 关键经验
- OJ 题单页是服务端渲染，直接 curl + 按 `<h4 class="ui top attached block header">` 分段即可解析题面；
  样例块在 `id="problem_example"` 内，存在两种写法：`<strong>样例输入</strong>`（新题）和 `<h4>输入样例</h4>`（老题）。
- 解析样例时正则不要写 `样例输入\s*\d*`，`\s*` 会跨行吃掉样例正文开头的数字（如把 `4 3` 吃成 ` 3`）；
  正确写法是 `样例输入[ \t]*\d*`（禁止跨行）。
- 测试数据不是手算的：先写 C++ 参考代码 → 本地 g++ 编译 → 跑输入拿真实输出 → 再生成 testCases，避免手算错误。
  已验证与 OJ 样例完全一致（如 4239 自整除数 47 的输出、1217 金币 1000→29820）。
- OJ 题面里的数学公式被渲染成 SVG/图片，抓下来会丢失（如 4238 立方和、1217 金币的公式），需人工在 stem 中补全描述。
