## Bug 修复：交卷后再次进入同一试卷，带着上次的作答记录

**根因**（`src/pages/ExamPage.tsx`）：useEffect 清理函数时序问题。

`handleSubmit` 流程：
1. `clearProgress(...)` 清除 localStorage 中的答题进度
2. `navigate('/result')` 路由跳转 → ExamPage 组件卸载
3. useEffect 清理函数执行，里面又调用了 `saveProgress(...)`，把答案**重新写回** localStorage

下次进入同一试卷，`useState(() => loadProgress(...))` 就会读到上次的作答。

**修复**（3 处微改）：
1. 新增 `submittedRef = useRef<boolean>(false)` 标记是否已交卷
2. useEffect 清理函数：若 `submittedRef.current === true` 则跳过最终保存
3. `handleSubmit`：先 `submittedRef.current = true`，再 `clearProgress(...)`，最后 `navigate(...)`；并删除冗余的 `saveProgress(...)` 调用（紧跟在 clearProgress 之前的写入纯无效操作）

**未影响的功能**：退出考试（点"退出"按钮直接 navigate('/')）仍保留进度——因为不走 `handleSubmit`，`submittedRef` 保持 false，清理函数照常保存。

**类型检查**：`tsc --noEmit` 通过，零错误。

## 首页视图状态持久化（升级：route state → storage）

**背景**：route state 方案无法记住 tab 筛选；且初次滚动失效（listHeight=0，react-window 的 scrollToItem 在容器未测量完成时不生效）。

**方案升级**：
- `storage.ts`：新增 `HomeViewState`（examId + categoryFilter + keyword）+ `saveHomeState`/`loadHomeState`，key 为 `cpp_exam_home_state`
- `HomePage.tsx`：
  - `savedHomeState = useMemo(() => loadHomeState(), [])`，初始化 selectedExam/categoryFilter/keyword 全部从中恢复
  - 新增 `useEffect`：三者任一变化即 `saveHomeState`
  - 滚动 useEffect 改为依赖 `selectedExam`（不再依赖 location.state）：`listHeight > 0` 时 `scrollToItem(idx, 'smart')`
- `ExamPage.tsx`：退出 `navigate('/')` 不再传 state

**效果**：退出考试返回、甚至刷新页面，都能恢复选中试卷 + tab 筛选 + 搜索词，并自动滚动定位。

**经验教训**：react-window 的 `scrollToItem` 在容器 height=0（ResizeObserver 未完成测量）时不生效，必须等 `listHeight > 0` 再调用。
