- 撤销之前的 name 交换：恢复为 name 与 id 一致的卷二/卷四；这样 mockExams 数组天然为 一→二→三→四
- 同时移除 HomePage 中额外的 sort 逻辑，让列表直接按 allExams 数组顺序展示
- 最终：全部 / 模拟卷 分类下都是从上到下「卷一、卷二、卷三、卷四」

- 交换模拟卷二与模拟卷四的 name（只改显示名，id 不动，避免历史练习记录按 examId 回放错乱）：

  - exam-mock-04（考纲五模块全覆盖内容）→ 显示「综合模拟卷二」
